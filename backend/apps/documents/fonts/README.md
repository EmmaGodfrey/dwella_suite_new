# Document fonts

Bundled for consistent offline PDF generation. SIL Open Font Licenses are included. Static instances were produced from the official Google Fonts variable files using fontTools.

- Figtree: google/fonts a60a77e14f28abd4ef243a1b5dfc48df0cec5205, ofl/figtree; static instances at [400, 600].
- Montserrat: google/fonts 8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5, ofl/montserrat; static instances at [600].
