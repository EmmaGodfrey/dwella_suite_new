# Frontend Template Reference

Dwella Suite uses the React starter kit as the active frontend base.

Use the full React template as the first reference whenever a new dashboard component is needed:

```text
C:\Users\OMEN\Desktop\EGLabs\react.zip
C:\Users\OMEN\Desktop\EGLabs\.template_compare\react-theme\Viho-Vite-React
```

Prefer adapting components from the React template before creating new UI from scratch. Create custom components only when the template does not provide a suitable pattern or the product workflow needs a simpler, cleaner interaction.

The old Nuxt template was intentionally removed from the app frontend because Dwella Suite is an authenticated admin dashboard and does not need Nuxt SSR.
