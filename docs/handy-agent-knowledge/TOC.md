# Dwella Suite knowledge base

Revision: 2026-10-28. Read the overview and access rules first. This package
does not grant database access or activate features in another environment.

- `00-overview.md` - Read first for Dwella's business model, identifiers, currencies, dates, and universal answering rules.
- `01-data-access-rules.md` - Read before every database query or action to enforce organization scope, role permissions, sensitive-data limits, and deny-by-default access.
- `02-properties-and-units.md` - Read for questions or actions involving properties, units, property types, management status, occupancy, or expected rent.
- `03-tenants-and-leases.md` - Read for questions or actions involving tenants, lease terms, lease status, occupancy relationships, or draft leases.
- `04-invoices-and-payments.md` - Read for invoices, charges, balances, arrears, collections, payment recording, payment methods, receipts, or reversals.
- `05-maintenance.md` - Read for vendors, maintenance requests, priorities, categories, access permission, status, or maintenance comments.
- `06-common-questions.md` - Read when calculating occupancy, rent roll, outstanding balances, arrears, collections, or property performance.
- `07-actions.md` - Read before proposing or executing any write action through Dwella's approved assistant API.
- `08-settings-and-account-help.md` - Read for roles, settings, beta signup,
  tenant access, communications and assistant connection guidance.
